# Hệ thống mạng Wireless — IUH

Kho tài liệu học tập môn **Hệ thống mạng Wireless** tại IUH.

## Nội dung

| Thư mục | Nội dung |
|---|---|
| `00_Chuong_trinh_mon_hoc/` | Tài liệu chương trình/ôn tập môn học |
| `01_Bai_giang/` | Bài giảng chương 1–7 và tài liệu tổng hợp |
| `02_Giao_trinh/` | Giáo trình Mobile Wireless Communications |
| `03_On_tap/` | Tài liệu ôn tập giữa kỳ và các tài liệu ôn tập khác |
| `04_Tai_lieu_tieng_Anh/` | Tài liệu tiếng Anh/bản dịch |
| `05_File_goc/` | File nén và tài liệu gốc |

Repository hiện có bài giảng chương 1–7, tài liệu tổng hợp môn, giáo trình *Mobile Wireless Communications*, tài liệu ôn tập và bản tiếng Việt của giáo trình. 

## Mục đích

- Hệ thống hóa tài liệu môn Hệ thống mạng Wireless.
- Dễ tra cứu bài giảng theo chương.
- Hỗ trợ học tập và ôn tập.
- Lưu giữ giáo trình và tài liệu tiếng Anh/bản dịch.

## Lưu ý

Một số tài liệu có thể thuộc bản quyền của giảng viên, tác giả hoặc nhà xuất bản. Vui lòng sử dụng cho mục đích học tập và tôn trọng quyền sở hữu trí tuệ.
